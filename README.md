# ✂️ Rock Paper Scissors

Juego interactivo de **Piedra, Papel o Tijeras** con múltiples modos de juego y funcionalidades avanzadas, desarrollado para practicar lógica de juegos, animaciones, gestión de estados y experiencia de usuario.

Esta versión incluye un modo **first-to-5** y animaciones de victoria y derrota.

---

## 🎮 Demo
👉 **Deploy:** [(link)](https://rock-paper-scissors-jade-six.vercel.app/)  

---

## ✨ Características principales
- ✔️ Modos de juego: clásico, first-to-5  
- ✔️ Animaciones de victoria y derrota con overlay suave  
- ✔️ Pantalla de victoria al completar el modo first-to-5 
- ✔️ Interfaz moderna, intuitiva y responsiva  
- ✔️ Control de puntuación y reset de partida  
- ✔️ Feedback visual y sonoro

## 🎯 Cómo jugar
1. Selecciona tu jugada: Piedra, Papel o Tijeras.  
2. La IA responde automáticamente.  
3. La app muestra el resultado y actualiza la puntuación.  
4. En el modo **first-to-5**, gana el primero que llegue a 5 victorias y se muestra una pantalla de victoria con opción de volver a jugar.
